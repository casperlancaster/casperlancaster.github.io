TRUCKZSIM

A C++ trucking-company management simulation built around real dispatch operations, fleet management, driver availability, fuel, finances, repairs and company persistence. These are genuine screenshots from my running console application and source code in Visual Studio.

What I built

TruckzSim connects individual trucks, drivers and loads to a company-management system. Players can assign and complete deliveries, manage operating costs, check equipment status, and save or reload their companies.

How it was built

I organized the game into C++ classes and dedicated manager components. During development I refactored the application, improved input validation, resolved compiler and linker issues, and used GitHub branches and pull requests to track progress.
